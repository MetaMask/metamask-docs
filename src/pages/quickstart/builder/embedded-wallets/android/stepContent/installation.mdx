### Install the Embedded Wallet SDK

Add the Web3Auth by MetaMask, Embedded Wallet SDK for Android to the dependency list of the app-level `build.gradle` file.
Ensure you're using the latest `com.github.Web3Auth:web3auth-android-sdk` package.

:::warning Update to the latest SDK

View the release notes to ensure you're using the [latest version](https://github.com/Web3Auth/web3auth-android-sdk/releases) of
the Android SDK.

:::
