### Make blockchain calls

After the user signs in, pass `useWeb3Auth().connection.ethereumProvider` to viem:

```tsx
import { useWeb3Auth } from '@web3auth/react-native-sdk'
import { createPublicClient, createWalletClient, custom, formatEther } from 'viem'

function BlockchainActions() {
  const { connection } = useWeb3Auth()

  const getBalance = async () => {
    const transport = custom(connection!.ethereumProvider!)
    const walletClient = createWalletClient({ transport })
    const publicClient = createPublicClient({ transport })
    const [address] = await walletClient.getAddresses()
    return formatEther(await publicClient.getBalance({ address }))
  }

  // ...
}
```

`connection` is `null` until sign-in completes, so read it only after `isConnected` is `true`.

:::tip Connect any blockchain

See the [Embedded Wallets documentation](/embedded-wallets/connect-blockchain) to learn more about making calls on any supported blockchain.

:::
