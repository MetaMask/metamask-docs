### Sign out the user

Call `disconnect` from the [`useWeb3AuthDisconnect`](/embedded-wallets/sdk/react-native/hooks/useWeb3AuthDisconnect)
hook to sign the user out. This ends the session and removes it from device storage.

:::info

The Embedded Wallets React Native SDK provides additional functions.
See the [functions reference](/embedded-wallets/sdk/react-native/usage) for more information.

:::
