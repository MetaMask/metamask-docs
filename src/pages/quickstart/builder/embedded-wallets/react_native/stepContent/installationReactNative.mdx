### Install the Embedded Wallets SDK

Install the MetaMask Embedded Wallets React Native SDK and its peer packages:

```bash
npm install @web3auth/react-native-sdk @toruslabs/react-native-web-browser react-native-encrypted-storage
npm install react-native-quick-crypto react-native-nitro-modules react-native-quick-base64
npm install --save-dev @babel/plugin-transform-export-namespace-from
```

`react-native-quick-crypto` 1.x is required; the SDK setup module installs it as the global
`crypto` object that sign-in uses.
