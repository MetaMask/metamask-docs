### Android prerequisites

Use the Android versions your React Native version requires. The quickstart uses React Native 0.84
and sets:

- `minSdkVersion` 24
- `compileSdkVersion` 36
- `targetSdkVersion` 36

Update the versions in `android/build.gradle`. Also register your redirect URL scheme in an
intent filter on `MainActivity`; see [Configure Android](/embedded-wallets/sdk/react-native#2-configure-android).
