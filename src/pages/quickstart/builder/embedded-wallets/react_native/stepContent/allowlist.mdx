### Allowlist your redirect URL

The SDK returns to your app through the `redirectUrl` you set in `web3authConfig.ts`, for example
`web3authrnexample://auth`. To allowlist it:

1. In the [MetaMask Developer Dashboard](https://developer.metamask.io), select your project.

1. Select the **Domains** tab. In **Allowlist URLs**, add the exact `redirectUrl` value.
