### Install the Embedded Wallet SDK

Install the Web3Auth by MetaMask, Embedded Wallet SDK (`@web3auth/modal`), Wagmi, and TanStack Query.
This quickstart uses Wagmi for blockchain calls.

```bash
npm install --save @web3auth/modal wagmi @tanstack/react-query
```
