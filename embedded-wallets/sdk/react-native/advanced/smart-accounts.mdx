## Enable smart accounts

Enable and configure smart accounts (account type, bundler, and paymaster for each chain) in your
project on the [Embedded Wallets dashboard](https://developer.metamask.io/). The SDK reads this
configuration during initialization, so no code change is needed.

To override the dashboard settings, pass `accountAbstractionConfig` in `web3AuthOptions`. Values
you pass are merged with the dashboard configuration. Set `accountAbstractionConfig` to `null` to
turn smart accounts off in your app even when they're enabled on the dashboard.

```typescript title="web3authConfig.ts"
import {
  WEB3AUTH_NETWORK,
  type AccountAbstractionConfig,
  type Web3AuthContextConfig,
} from '@web3auth/react-native-sdk'

const aaConfig: AccountAbstractionConfig = {
  smartAccountType: 'safe',
}

const web3AuthConfig: Web3AuthContextConfig = {
  web3AuthOptions: {
    clientId: '<YOUR_CLIENT_ID>',
    redirectUrl: 'yourapp://auth',
    network: WEB3AUTH_NETWORK.SAPPHIRE_MAINNET,
    // highlight-next-line
    accountAbstractionConfig: aaConfig,
  },
}

export default web3AuthConfig
```

For ERC-4337 smart accounts, each smart account chain needs a bundler URL and a matching entry in
`chains` (or on the dashboard). Initialization fails if a smart account chain has no bundler URL or
chain configuration. The SDK skips this check for EIP-7702 smart accounts.

:::tip Toggle smart accounts at runtime

`Web3AuthProvider` creates a new SDK instance when `config.web3AuthOptions` changes identity. To switch between smart
accounts and an externally owned account (EOA), build the config from state and pass a new `key`
so the provider remounts:

```tsx
const [useAA, setUseAA] = useState(false)
const config = useMemo(() => getWeb3AuthConfig(useAA), [useAA])

return (
  <Web3AuthProvider
    key={useAA ? 'aa' : 'eoa'}
    webBrowser={WebBrowser}
    storage={Storage}
    config={config}>
    {/* ... */}
  </Web3AuthProvider>
)
```

Where `getWeb3AuthConfig(useAA)` returns `accountAbstractionConfig: useAA ? aaConfig : null`.

:::

## Use the smart account

The rest of this page applies to ERC-4337 smart accounts. With them enabled,
`connection.ethereumProvider` sends transactions as user operations from the smart account. Use it
with viem, ethers, or [Wagmi](../ethereum-hooks.mdx).

:::note EIP-7702

When the smart account EIP standard is EIP-7702, the SDK doesn't wrap the provider in the
ERC-4337 smart account provider. `connection.ethereumProvider` is the EOA provider, so the address
order and user operation behavior below don't apply.

:::

### Get the smart account address

The first address is the smart account, and the second is the EOA that signs for it:

```tsx
import { useWeb3Auth } from '@web3auth/react-native-sdk'
import { createWalletClient, custom } from 'viem'

const { connection } = useWeb3Auth()
const walletClient = createWalletClient({ transport: custom(connection!.ethereumProvider!) })

const [smartAccountAddress, eoaAddress] = await walletClient.getAddresses()
```

### Send a transaction

Provide only `to`, `value`, and `data`. The SDK builds the user operation, sets gas fees through the
bundler, and submits it. The first transaction also deploys the smart account.

```tsx
import { parseEther } from 'viem'

const hash = await walletClient.sendTransaction({
  account: smartAccountAddress,
  to: '<DESTINATION_ADDRESS>',
  value: parseEther('0.001'),
  chain: null,
})
```
