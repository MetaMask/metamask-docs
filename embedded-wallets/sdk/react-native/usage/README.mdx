The following pages show how to perform common operations with the v10 hooks. Use all hooks inside
`Web3AuthProvider`.

| Task                          | Hook                                            | Page                                      |
| ----------------------------- | ----------------------------------------------- | ----------------------------------------- |
| Sign in                       | `useWeb3AuthConnect()` → `connectTo()`          | [Sign in](./login.mdx)                    |
| Sign out                      | `useWeb3AuthDisconnect()` → `disconnect()`      | [Sign out](./logout.mdx)                  |
| Read the user profile         | `useWeb3AuthUser()` → `userInfo`                | [User info](./user-info.mdx)              |
| Make EVM calls                | `useWeb3Auth()` → `connection.ethereumProvider` | [EVM provider](./private-key.mdx)         |
| Make Solana calls             | Hooks from `@web3auth/react-native-sdk/solana`  | [Solana wallet](./ed25519-key.mdx)        |
| Enable MFA                    | `useEnableMFA()` → `enableMFA()`                | [Enable MFA](./enable-mfa.mdx)            |
| Open Wallet Services          | `useWalletUI()` → `showWalletUI()`              | [Wallet UI](./launch-wallet-services.mdx) |
| Request a confirmed signature | `useSignatureRequest()` → `request()`           | [Signature request](./request.mdx)        |

To map v9 or earlier APIs to v10, see the
[React Native migration guide](/embedded-wallets/migration-guides/react-native).
