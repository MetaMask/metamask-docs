Hook to open the Wallet Services UI in the in-app browser. Wallet Services gives users a prebuilt
wallet interface for viewing balances, sending and receiving tokens, and more.

### Import

```tsx
import { useWalletUI } from '@web3auth/react-native-sdk'
```

### Usage

```tsx
import { useWalletUI } from '@web3auth/react-native-sdk'
import { Button, Text, View } from 'react-native'

function WalletButton() {
  const { showWalletUI, loading, error } = useWalletUI()

  return (
    <View>
      <Button
        title={loading ? 'Opening wallet…' : 'Open wallet'}
        disabled={loading}
        onPress={() => showWalletUI()}
      />
      {error && <Text>{error.message}</Text>}
    </View>
  )
}
```

### Return type

```tsx
import { type IUseWalletUI } from '@web3auth/react-native-sdk'
```

#### `showWalletUI`

`(path?: string) => Promise<void>`

Opens Wallet Services in the in-app browser. The optional `path` selects the Wallet Services page
to open; the default is `wallet`. Requires a signed-in user; otherwise `showWalletUI` sets `error`.

#### `loading`

`boolean`

`true` while the wallet is opening.

#### `error`

`Web3authRNError | null`

Error from the most recent `showWalletUI` call, or `null`.

:::info

Configure Wallet Services on the dashboard, or override settings with `walletServicesConfig` in
`web3AuthOptions`. See [Advanced configuration](../advanced/README.mdx#web3authoptions-reference).

:::
