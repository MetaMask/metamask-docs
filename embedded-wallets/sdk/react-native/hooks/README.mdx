The Embedded Wallets React Native SDK exposes its features through React hooks. Use all hooks
inside the `Web3AuthProvider` component tree.

## Core hooks

| Hook                               | Description                                                                                        |
| ---------------------------------- | -------------------------------------------------------------------------------------------------- |
| [`useWeb3Auth`](./useWeb3Auth.mdx) | SDK state (`isConnected`, `isInitializing`, `initError`), the wallet `connection`, and `web3Auth`. |

## Authentication hooks

| Hook                                                   | Description                                     |
| ------------------------------------------------------ | ----------------------------------------------- |
| [`useWeb3AuthConnect`](./useWeb3AuthConnect.mdx)       | Sign a user in with `connectTo`.                |
| [`useWeb3AuthDisconnect`](./useWeb3AuthDisconnect.mdx) | Sign the user out.                              |
| [`useRefreshSession`](./useRefreshSession.mdx)         | Revalidate the session and reload session data. |

## Identity hooks

| Hook                                         | Description                                            |
| -------------------------------------------- | ------------------------------------------------------ |
| [`useWeb3AuthUser`](./useWeb3AuthUser.mdx)   | The signed-in user's profile and MFA status.           |
| [`useAuthTokenInfo`](./useAuthTokenInfo.mdx) | Identity token (JWT) for server-side verification.     |
| [`useAccessToken`](./useAccessToken.mdx)     | Embedded Wallets access token for the current session. |
| [`useIdentityToken`](./useIdentityToken.mdx) | Deprecated. Use `useAuthTokenInfo` instead.            |

## Multi-factor authentication hooks

| Hook                                 | Description                                     |
| ------------------------------------ | ----------------------------------------------- |
| [`useEnableMFA`](./useEnableMFA.mdx) | Start MFA setup for the signed-in user.         |
| [`useManageMFA`](./useManageMFA.mdx) | Manage MFA factors for a user with MFA enabled. |

## Wallet Services hooks

| Hook                                               | Description                                                        |
| -------------------------------------------------- | ------------------------------------------------------------------ |
| [`useWalletUI`](./useWalletUI.mdx)                 | Open the Wallet Services UI.                                       |
| [`useSignatureRequest`](./useSignatureRequest.mdx) | Request a signature with a confirmation screen in Wallet Services. |

## Chain-specific hooks

- [Ethereum hooks (Wagmi)](../ethereum-hooks.mdx) from `@web3auth/react-native-sdk/wagmi`
- [Solana hooks](../solana-hooks.mdx) from `@web3auth/react-native-sdk/solana`: `useSolanaWallet`,
  `useSignMessage`, `useSignTransaction`, and `useSignAndSendTransaction`
