## Overview

The MetaMask Embedded Wallets SDK for React Native (`@web3auth/react-native-sdk`) adds social
sign-in and wallet functionality to your iOS and Android apps. Wrap your app in `Web3AuthProvider`
and use React hooks to sign users in, read the wallet connection, and open Wallet Services.

This page covers v10 of the SDK. After sign-in, `useWeb3Auth().connection` exposes an EIP-1193
`ethereumProvider` for EVM chains and a Wallet Standard `solanaWallet` for Solana. Optional
entry points add [Wagmi hooks](./ethereum-hooks.mdx) (`@web3auth/react-native-sdk/wagmi`) and
[Solana hooks](./solana-hooks.mdx) (`@web3auth/react-native-sdk/solana`).

:::info Migrate from an earlier version

See the [React Native migration guide](/embedded-wallets/migration-guides/react-native) to upgrade
from any earlier `@web3auth/react-native-sdk` version.

:::

## Requirements

- Node.js 22 or later.
- React Native. The official bare examples use React Native 0.84.
- For Expo, a [development build](https://docs.expo.dev/develop/development-builds/introduction/),
  because the SDK uses the native module `react-native-quick-crypto`.
- iOS: deployment target supported by your React Native version. Sign-in uses
  `ASWebAuthenticationSession`.
- Android: a browser that supports Custom Tabs.

## Prerequisites

Set up your project on the [Embedded Wallets dashboard](https://developer.metamask.io/):

1. Create a project and copy the **Client ID**.
1. Choose a custom URL scheme for your app (for example, `web3authrnexample`) and add the full
   redirect URL you pass to the SDK (for example, `web3authrnexample://auth`) to the allowlist.
1. Configure the chains your app uses, or pass them in code with `chains`.

See the [dashboard setup guide](../../dashboard/README.mdx) for details.

## Install

### 1. Install the SDK and its peer packages

The SDK needs an in-app browser, secure storage, and a native crypto implementation. The packages
differ between bare React Native and Expo:

<TabItem value="bare">

```bash npm2yarn
npm install @web3auth/react-native-sdk @toruslabs/react-native-web-browser react-native-encrypted-storage
npm install react-native-quick-crypto react-native-nitro-modules react-native-quick-base64
npm install --save-dev @babel/plugin-transform-export-namespace-from
```

</TabItem>

<TabItem value="expo">

```bash
npx expo install react-native-quick-crypto react-native-nitro-modules react-native-quick-base64
npm install --save-dev @babel/plugin-transform-export-namespace-from
```

</TabItem>

</Tabs>

:::caution `react-native-quick-crypto` is required

`@web3auth/react-native-sdk/setup` installs `react-native-quick-crypto` as the global `crypto`
object. Sign-in needs `crypto.getRandomValues`, and the Metro `crypto-browserify` fallback doesn't
provide it. If `react-native-quick-crypto` is missing or its native library fails to load, the SDK
initializes but `connectTo` fails with `TypeError: undefined is not a function` in `randomBytes`.

Use `react-native-quick-crypto` 1.x. Version 0.7.x doesn't load on Android devices with 16 KB
memory pages.

:::

### 2. Configure Android

Register your URL scheme on the main activity in `android/app/src/main/AndroidManifest.xml` so the
in-app browser can return to your app. Set `android:launchMode="singleTask"` and
`android:exported="true"`:

```xml title="android/app/src/main/AndroidManifest.xml"
<activity
  android:name=".MainActivity"
  android:launchMode="singleTask"
  android:exported="true">
  <!-- existing MAIN / LAUNCHER intent filter -->
  <intent-filter>
    <action android:name="android.intent.action.VIEW" />
    <category android:name="android.intent.category.DEFAULT" />
    <category android:name="android.intent.category.BROWSABLE" />
    <!-- replace with your own scheme -->
    <data android:scheme="web3authrnexample" />
  </intent-filter>
</activity>
```

:::warning Gradle 9 and `@toruslabs/react-native-web-browser`

`@toruslabs/react-native-web-browser` 1.1.0 calls `jcenter()` in its `android/build.gradle`.
Gradle 9, which React Native 0.84 uses, removed `jcenter()`, so the Android build fails with
`Could not find method jcenter()`. Until a fixed version is released, replace `jcenter()` with
`mavenCentral()` in `node_modules/@toruslabs/react-native-web-browser/android/build.gradle` and
persist the change with [`patch-package`](https://www.npmjs.com/package/patch-package).

:::

### 3. Configure iOS

Install pods:

```bash
cd ios && pod install
```

### 4. Configure Expo

Add your scheme to `app.json`, then create a development build with `npx expo prebuild` or EAS
Build:

```json title="app.json"
{
  "expo": {
    "scheme": "web3authexpoexample"
  }
}
```

Build the redirect URL with `expo-linking`. Expo Go and development or standalone builds resolve
different URLs, so allowlist each URL your app uses:

```ts
import Constants, { AppOwnership } from 'expo-constants'
import * as Linking from 'expo-linking'

const redirectUrl =
  Constants.appOwnership === AppOwnership.Expo
    ? Linking.createURL('web3auth', {})
    : Linking.createURL('web3auth', { scheme: 'web3authexpoexample' })
```

## Sign users in

Call `connectTo` from the `useWeb3AuthConnect` hook. The SDK opens the sign-in flow in an in-app
browser and returns to your app through `redirectUrl`.

```tsx
import { AUTH_CONNECTION, useWeb3Auth, useWeb3AuthConnect } from '@web3auth/react-native-sdk'
import { ActivityIndicator, Button, View } from 'react-native'

function Screen() {
  const { isConnected, isInitializing } = useWeb3Auth()
  const { connectTo, loading } = useWeb3AuthConnect()

  if (isInitializing) return <ActivityIndicator />
  if (isConnected) return <HomeView />

  return (
    <View>
      <Button
        title={loading ? 'Signing in…' : 'Sign in with Google'}
        disabled={loading}
        onPress={() => connectTo({ authConnection: AUTH_CONNECTION.GOOGLE })}
      />
      <Button
        title="Sign in with email"
        disabled={loading}
        onPress={() =>
          connectTo({
            authConnection: AUTH_CONNECTION.EMAIL_PASSWORDLESS,
            extraLoginOptions: { login_hint: 'user@example.com' },
          })
        }
      />
    </View>
  )
}
```

See [Sign in](./usage/login.mdx) and [`useWeb3AuthConnect`](./hooks/useWeb3AuthConnect.mdx) for
all `connectTo` parameters.

## Make EVM calls

After sign-in, pass `connection.ethereumProvider` to viem or ethers:

```tsx
import { useWeb3Auth } from '@web3auth/react-native-sdk'
import { createWalletClient, custom } from 'viem'

function HomeView() {
  const { connection } = useWeb3Auth()

  const signMessage = async () => {
    const walletClient = createWalletClient({
      transport: custom(connection!.ethereumProvider!),
    })
    const [account] = await walletClient.getAddresses()
    return walletClient.signMessage({ account, message: 'Hello' })
  }

  // ...
}
```

To use Wagmi hooks instead, see [Ethereum hooks (Wagmi)](./ethereum-hooks.mdx).
