Hook to access the Wallet Services plugin context. It returns the plugin instance and its connection
state. For common actions, prefer the dedicated hooks: [`useWalletUI`](./useWalletUI.mdx),
[`useCheckout`](./useCheckout.mdx), [`useSwap`](./useSwap.mdx),
[`useFunding`](./useFunding.mdx), [`useReceive`](./useReceive.mdx), and
[`useWalletConnectScanner`](./useWalletConnectScanner.mdx).

:::info

Please note that this hook doesn't work for external wallet logins. It only works for social login embedded wallets.

:::

### Import

```tsx
import { useWalletServicesPlugin } from '@web3auth/modal/react'
```

### Usage

```tsx
import { useWalletServicesPlugin } from '@web3auth/modal/react'

function WalletServicesExample() {
  const { plugin, ready, connecting } = useWalletServicesPlugin()

  return (
    <div>
      <button onClick={() => plugin?.showWalletConnectScanner()} disabled={!ready}>
        Show WalletConnect Scanner
      </button>
      <button onClick={() => plugin?.showCheckout()} disabled={!ready}>
        Show Checkout
      </button>
      <button onClick={() => plugin?.showWalletUi()} disabled={!ready}>
        Show Wallet UI
      </button>
      {connecting && <div>Connecting Wallet Services...</div>}
    </div>
  )
}
```

### Return type

```tsx
import { type IWalletServicesContext } from '@web3auth/modal/react'
```

#### `ready`

`boolean`

Whether the Wallet Services plugin is connected and ready to use.

#### `connecting`

`boolean`

Whether the Wallet Services plugin is currently connecting.

#### `plugin`

`WalletServicesPluginType | null`

The Wallet Services plugin instance, or `null` if it's not available. The plugin exposes
`showWalletUi`, `showCheckout`, `showSwap`, `showFunding`, `showReceive`, and
`showWalletConnectScanner`. Each method throws if the plugin isn't connected.
