---
title: Sign out a user
sidebar_label: Sign out
description: 'Sign out a user with the MetaMask Embedded Wallet SDK for Unity.'
---

Call `logout` to end the current session.
Subscribe to `onLogout` to run code after sign-out completes.

:::tip

```cs
void Start()
{
    web3Auth = GetComponent<Web3Auth>();
    web3Auth.setOptions(new Web3AuthOptions()
    {

    });
    // focus-next-line
    web3Auth.onLogout += onLogout;
}
//focus-start
private void onLogout()
{
    // Functions to be called after user logs out
}
//focus-end
```

:::

## Usage

```cs
public void logout()
{
    web3Auth.logout();
}

private void onLogout()
{
    Debug.Log("Signed out");
}
```
