The `getAccessToken` method returns the access token of the current Web3Auth session.

This method throws `Web3AuthError.noUserFound` if no access token is available, for example when
no user is signed in.

## Usage

```swift
do {
    // focus-next-line
    let accessToken = try await web3Auth.getAccessToken()
} catch {
    print(error.localizedDescription)
    // Handle error
}
```
