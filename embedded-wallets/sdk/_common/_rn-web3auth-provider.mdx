`Web3AuthProvider` is the React context provider that initialises the SDK and makes all hooks available to the component tree.

<Tabs
  defaultValue="bare"

  ]}

<TabItem value="bare">

```tsx
import * as WebBrowser from '@toruslabs/react-native-web-browser'
import EncryptedStorage from 'react-native-encrypted-storage'
import { Web3AuthProvider } from '@web3auth/react-native-sdk'
import web3AuthConfig from './web3authConfig'

export default function App() {
  return (
    <Web3AuthProvider webBrowser={WebBrowser} storage={EncryptedStorage} config={web3AuthConfig}>
      <Screen />
    </Web3AuthProvider>
  )
}
```

### Props

| Prop         | Type                              | Required | Description                                                                                                                     |
| ------------ | --------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `webBrowser` | `IWebBrowser`                     | Yes      | In-app browser implementation. Use `@toruslabs/react-native-web-browser` for bare React Native and `expo-web-browser` for Expo. |
| `storage`    | `EncryptedStorage \| SecureStore` | Yes      | Secure storage for session data. Use `react-native-encrypted-storage` for bare React Native and `expo-secure-store` for Expo.   |
| `config`     | `Web3AuthContextConfig`           | Yes      | `{ web3AuthOptions }` object, typically exported from `web3authConfig.ts`.                                                      |
| `children`   | `React.ReactNode`                 | Yes      | Components that use the Embedded Wallets hooks.                                                                                 |

The provider creates a new SDK instance whenever the `config.web3AuthOptions` object, `webBrowser`,
or `storage` changes identity. Define the config outside your component or memoize it. To switch
configurations at runtime (for example, to toggle account abstraction), pass a new React `key` to
remount the provider.
