<TabItem value="table">

| Parameter                  | Required | Description                                                                                                                                                                                                                                                                         |
| -------------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `authConnection`           | Yes      | Authentication method. Pass an `AUTH_CONNECTION.*` constant.                                                                                                                                                                                                                        |
| `authConnectionId?`        | No       | Connection ID from the dashboard. Required for `AUTH_CONNECTION.CUSTOM` and for grouped connections. Also use it to target a specific connection when you have several of the same type.                                                                                            |
| `groupedAuthConnectionId?` | No       | Grouped connection ID from the dashboard. Connections in the same group produce the same wallet for the same user.                                                                                                                                                                  |
| `idToken?`                 | No       | JWT from your own auth provider. When set, the SDK skips the in-app browser and derives the wallet from the token directly. Requires `authConnectionId`. See [Custom authentication](/embedded-wallets/sdk/react-native/advanced/custom-authentication#bring-your-own-jwt-idtoken). |
| `extraLoginOptions?`       | No       | Extra OAuth parameters for browser-based sign-in, for example `login_hint` (email or phone number for passwordless), `domain` (Auth0 domain), and `verifierIdField` (JWT claim used as the user ID).                                                                                |
| `mfaLevel?`                | No       | When to show the MFA setup screen: `'optional'`, `'mandatory'`, or `'none'` (`MFA_LEVELS.OPTIONAL`, `MFA_LEVELS.MANDATORY`, `MFA_LEVELS.NONE`).                                                                                                                                     |
| `curve?`                   | No       | Key curve: `SUPPORTED_KEY_CURVES.SECP256K1` or `SUPPORTED_KEY_CURVES.ED25519`.                                                                                                                                                                                                      |
| `dappShare?`               | No       | Dapp share for MFA-enabled custom connections. The SDK stores and reuses the dapp share automatically; see [Dapp share](/embedded-wallets/sdk/react-native/advanced/dapp-share).                                                                                                    |
| `appState?`                | No       | Custom state string returned in `userInfo.appState` after sign-in.                                                                                                                                                                                                                  |
| `dappUrl?`                 | No       | URL of your dapp, used for analytics.                                                                                                                                                                                                                                               |

</TabItem>
