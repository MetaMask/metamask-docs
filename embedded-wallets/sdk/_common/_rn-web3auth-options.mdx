<TabItem value="table">

| Parameter                  | Required | Description                                                                                                                                                                                                                               |
| -------------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `clientId`                 | Yes      | Client ID of your project on the [Embedded Wallets dashboard](https://developer.metamask.io).                                                                                                                                             |
| `redirectUrl`              | Yes      | Deep link the in-app browser returns to after sign-in, for example `yourapp://auth`. Must be allowlisted on the dashboard.                                                                                                                |
| `network`                  | Yes      | `WEB3AUTH_NETWORK.SAPPHIRE_MAINNET` or `WEB3AUTH_NETWORK.SAPPHIRE_DEVNET`. Must match the network of your dashboard project.                                                                                                              |
| `chains`                   | No       | Array of `CustomChainConfig` objects. Merged with the chains configured on the dashboard; entries with the same `chainId` override the dashboard values. Initialization fails if no chains are configured in either place.                |
| `defaultChainId`           | No       | Hex chain ID of the chain to use after sign-in. If not set, the SDK uses the first chain in the merged list. Dashboard chains come first in that list, so set `defaultChainId` if you configure chains both on the dashboard and in code. |
| `accountAbstractionConfig` | No       | Smart account configuration, merged with the dashboard smart account settings. Set to `null` to turn off smart accounts that are enabled on the dashboard.                                                                                |
| `useAAWithExternalWallet`  | No       | Whether to use smart accounts with external wallets. If not set, the SDK uses the dashboard wallet scope setting.                                                                                                                         |
| `walletServicesConfig`     | No       | Wallet Services settings, such as `confirmationStrategy` (`'default'`, `'auto-approve'`, or `'modal'`), `enableKeyExport`, and `whiteLabel`. Overrides the dashboard Wallet UI settings.                                                  |
| `whiteLabel`               | No       | Branding for the sign-in screens. Merged with the dashboard branding settings. See [Whitelabel](/embedded-wallets/sdk/react-native/advanced/whitelabel).                                                                                  |
| `mfaSettings`              | No       | MFA factor configuration. See [Multi-factor authentication](/embedded-wallets/sdk/react-native/advanced/mfa).                                                                                                                             |
| `sessionTime`              | No       | Session duration in seconds. If not set, the SDK uses the session duration configured on the dashboard (30 days by default).                                                                                                              |
| `authConnectionConfig`     | No       | Additional auth connection definitions, merged with the connections configured on the dashboard.                                                                                                                                          |
| `useCoreKitKey`            | No       | Use the Core Kit key instead of the default key. Only set this if you migrate users from a Core Kit integration.                                                                                                                          |
| `enableLogging`            | No       | Print SDK debug logs. The default is `false`.                                                                                                                                                                                             |
| `disableAnalytics`         | No       | Turn off the anonymous usage analytics that the SDK sends. The default is `false`.                                                                                                                                                        |
| `walletSdkURL`             | No       | Override the Wallet Services URL, for example to point at a staging deployment. If not set, the SDK picks the URL for `buildEnv` (production by default).                                                                                 |

</TabItem>
