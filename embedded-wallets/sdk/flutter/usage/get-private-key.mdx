To retrieve the secp256k1 private key of the user, use the `getPrivateKey` method. The method returns an EVM compatible private key which can be used to sign transactions on EVM compatible chains.

The method returns an empty string if the user isn't authenticated, so you can use it to check
for an existing session after [`initialize`](../README.mdx#initialize-web3auth).

## Usage

```dart
final privateKey = await Web3AuthFlutter.getPrivateKey();
```

:::note

Web3Auth supports two widely used cryptographic curves, Secp256k1 and Ed25519, making it chain-agnostic and compatible with multiple blockchain networks. [Learn more about how to connect different blockchains](/embedded-wallets/connect-blockchain).

:::
