This guide upgrades any earlier `@web3auth/react-native-sdk` version (v3 through v9) directly to
**v10** (`@web3auth/react-native-sdk@^10`). You don't need intermediate upgrades.

v10 is a hooks-based API. Wrap your app in `Web3AuthProvider` and use hooks such as
`useWeb3AuthConnect` and `useWeb3AuthDisconnect`. After sign-in, `useWeb3Auth().connection`
exposes `ethereumProvider` for EVM chains and `solanaWallet` for Solana.

- **From v9:** the hooks API stays the same. Follow [Migrate from v9](#migrate-from-v9).
- **From v8 or earlier:** follow the [full migration workflow](#migration-workflow).

Compare your result with the official
[React Native examples](https://github.com/Web3Auth/web3auth-react-native-examples), for example
[rn-bare-quick-start](https://github.com/Web3Auth/web3auth-react-native-examples/tree/main/rn-bare-quick-start)
and
[rn-bare-solana-example](https://github.com/Web3Auth/web3auth-react-native-examples/tree/main/rn-bare-solana-example).

## Migrate from v9

v9 and v10 share the provider and hooks. The changes are:

| v9                                                                    | v10                                                                                                |
| --------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `useWeb3Auth().provider`                                              | `useWeb3Auth().connection?.ethereumProvider`                                                       |
| `useWeb3Auth().web3Auth.signer` (Solana `TransactionSigner`)          | `connection?.solanaWallet` and the [Solana hooks](/embedded-wallets/sdk/react-native/solana-hooks) |
| `connectTo()` resolves with a `WalletResult` (`{ provider, signer }`) | `connectTo()` resolves with a `Connection` (`ethereumProvider`, `solanaWallet`)                    |
| `useIdentityToken().getIdentityToken()`                               | `useAuthTokenInfo().getAuthTokenInfo()` (`useIdentityToken` is deprecated)                         |
| None                                                                  | New hooks: `useAccessToken`, `useAuthTokenInfo`, `useRefreshSession`                               |
| None                                                                  | New entry points: `@web3auth/react-native-sdk/wagmi` and `@web3auth/react-native-sdk/solana`       |
| `mfaLevel` in `web3AuthOptions` (shown in earlier docs)               | Not an SDK option; pass `mfaLevel` to `connectTo`                                                  |
| Any Solana chain ID (earlier docs used `0x1` to `0x3`)                | `0x65` (Mainnet), `0x66` (Testnet), or `0x67` (Devnet), required for the Solana wallet             |

### 1. Update packages

```bash npm2yarn
npm install @web3auth/react-native-sdk@^10.0.0
```

Keep `react-native-quick-crypto` installed: `@web3auth/react-native-sdk/setup` installs it as the
global `crypto` object that sign-in uses. Use 1.x for React Native 0.75 or later with the New
Architecture, and 0.7.x for earlier versions. See
[Install](/embedded-wallets/sdk/react-native#1-install-the-sdk-and-its-peer-packages). Remove
`@solana/signers` if only Embedded Wallets code used it.

### 2. Replace `provider` with `connection.ethereumProvider`

```diff
- const { provider } = useWeb3Auth()
- const ethersProvider = new ethers.BrowserProvider(provider!)
+ const { connection } = useWeb3Auth()
+ const ethersProvider = new ethers.BrowserProvider(connection!.ethereumProvider!)
```

`connection` is `null` until the user signs in. Read it inside event handlers or after checking
`isConnected`, not unconditionally during render.

### 3. Move Solana code to the Solana hooks

Replace `web3Auth.signer` with the hooks from `@web3auth/react-native-sdk/solana`, and set up
`SolanaProvider` and the Solana polyfills as described in
[Solana hooks](/embedded-wallets/sdk/react-native/solana-hooks#set-up).

```diff
- import type { TransactionSigner } from '@solana/signers'
- const { web3Auth } = useWeb3Auth()
- const signer = web3Auth?.signer as TransactionSigner | null
- const address = signer ? String(signer.address) : null
+ import { useSolanaWallet } from '@web3auth/react-native-sdk/solana'
+ const { accounts } = useSolanaWallet()
+ const address = accounts?.[0] ?? null
```

### 4. Update `connectTo` handling

```diff
- const { provider } = await connectTo({ authConnection: AUTH_CONNECTION.GOOGLE })
+ const connection = await connectTo({ authConnection: AUTH_CONNECTION.GOOGLE })
+ if (!connection) {
+   // same as v9: read `error` from useWeb3AuthConnect()
+ }
```

### 5. Replace deprecated and moved options

- Replace `useIdentityToken` with [`useAuthTokenInfo`](/embedded-wallets/sdk/react-native/hooks/useAuthTokenInfo).
- Move `mfaLevel` from `web3AuthOptions` to `connectTo`.
- Change Solana chain IDs to `0x65`, `0x66`, or `0x67`.

Then run the [verification checklist](#verification-checklist).

## API mapping (v8 and earlier to v10)

| Legacy (v3 to v8)                                        | v10 replacement                                                            |
| -------------------------------------------------------- | -------------------------------------------------------------------------- |
| `new Web3Auth(browser, storage, options)` + `init()`     | `<Web3AuthProvider webBrowser storage config>` (initializes automatically) |
| `new Web3Auth(browser, options)` (no storage)            | Add storage and use `Web3AuthProvider`                                     |
| `OPENLOGIN_NETWORK.*`                                    | `WEB3AUTH_NETWORK.*`                                                       |
| `LOGIN_PROVIDER.*`                                       | `AUTH_CONNECTION.*`                                                        |
| `web3auth.login({ loginProvider, extraLoginOptions })`   | `useWeb3AuthConnect().connectTo({ authConnection, extraLoginOptions })`    |
| `web3auth.logout()`                                      | `useWeb3AuthDisconnect().disconnect()`                                     |
| `web3auth.userInfo()`                                    | `useWeb3AuthUser().userInfo`                                               |
| `web3auth.connected`                                     | `useWeb3Auth().isConnected`                                                |
| `web3auth.provider`, `EthereumPrivateKeyProvider`        | `useWeb3Auth().connection.ethereumProvider`                                |
| `SolanaPrivateKeyProvider`, `SolanaWallet`               | `connection.solanaWallet` and the Solana hooks                             |
| `web3auth.privKey` / `web3auth.ed25519Key`               | No direct getter; use the provider or Solana hooks                         |
| `privateKeyProvider` with a `chainConfig`                | Optional `chains` in `web3AuthOptions` or chains on the dashboard          |
| `loginConfig` + `verifier`                               | Dashboard connection + `authConnectionId` in `connectTo`                   |
| `verifierSubIdentifier`                                  | `groupedAuthConnectionId` in `connectTo`                                   |
| `LOGIN_PROVIDER.JWT` + `id_token` in `extraLoginOptions` | `AUTH_CONNECTION.CUSTOM` + `authConnectionId` + top-level `idToken`        |
| `useSFAKey`                                              | Removed                                                                    |
| `mfaLevel` in constructor options                        | `mfaLevel` in `connectTo`                                                  |
| `launchWalletServices(chainConfig)`                      | `useWalletUI().showWalletUI()`                                             |
| `request(chainConfig, method, params)`                   | `useSignatureRequest().request(method, params)`                            |
| `scheme://openlogin`                                     | `scheme://auth`                                                            |
| `whiteLabel.name`                                        | `whiteLabel.appName`                                                       |
| `whiteLabel.dark: boolean`                               | `whiteLabel.mode: 'light' \| 'dark' \| 'auto'`                             |
| `import './globals'`, `react-native-get-random-values`   | `import '@web3auth/react-native-sdk/setup'` as the first line              |
| Manual Metro `extraNodeModules`                          | `withWeb3Auth(getDefaultConfig(__dirname))`                                |

### Step 5: `web3authConfig.ts`

Move `clientId`, `redirectUrl`, `network`, and optional settings into a `Web3AuthContextConfig`.
`chains` is optional when you configure chains on the
[dashboard](/embedded-wallets/dashboard/chains-and-networks/).

```typescript title="web3authConfig.ts"
import { WEB3AUTH_NETWORK, type Web3AuthContextConfig } from '@web3auth/react-native-sdk'

const web3AuthConfig: Web3AuthContextConfig = {
  web3AuthOptions: {
    clientId: '<YOUR_CLIENT_ID>',
    redirectUrl: 'yourapp://auth',
    network: WEB3AUTH_NETWORK.SAPPHIRE_MAINNET,
    whiteLabel: {
      appName: 'My App',
      mode: 'auto',
    },
  },
}

export default web3AuthConfig
```

Delete `privateKeyProvider`, `loginConfig`, `useSFAKey`, and `mfaLevel` from the options. For
Solana, use chain IDs `0x65`, `0x66`, or `0x67`. See [Configure the SDK](/embedded-wallets/sdk/react-native#configure-the-sdk).

### Step 6: App root

```tsx title="App.tsx"
import * as WebBrowser from '@toruslabs/react-native-web-browser' // Expo: 'expo-web-browser'
import { Web3AuthProvider, useWeb3Auth } from '@web3auth/react-native-sdk'
import EncryptedStorage from 'react-native-encrypted-storage' // Expo: * as SecureStore from 'expo-secure-store'

import web3AuthConfig from './web3authConfig'

function RootScreen() {
  const { isConnected, isInitializing } = useWeb3Auth()
  if (isInitializing) return null
  return isConnected ? <HomeScreen /> : <LoginScreen />
}

export default function App() {
  return (
    <Web3AuthProvider webBrowser={WebBrowser} storage={EncryptedStorage} config={web3AuthConfig}>
      <RootScreen />
    </Web3AuthProvider>
  )
}
```

Remove module-level `new Web3Auth(...)` and any `useEffect` that calls `init()`.

### Step 7: Sign-in and session hooks

```tsx
import {
  AUTH_CONNECTION,
  useWeb3AuthConnect,
  useWeb3AuthDisconnect,
  useWeb3AuthUser,
} from '@web3auth/react-native-sdk'

const { connectTo, error } = useWeb3AuthConnect()
const { disconnect } = useWeb3AuthDisconnect()
const { userInfo } = useWeb3AuthUser()

// Email passwordless
await connectTo({
  authConnection: AUTH_CONNECTION.EMAIL_PASSWORDLESS,
  extraLoginOptions: { login_hint: email },
})

// Custom JWT (no browser)
await connectTo({
  authConnection: AUTH_CONNECTION.CUSTOM,
  authConnectionId: '<YOUR_CONNECTION_ID>',
  idToken,
})

// Grouped connection
await connectTo({
  authConnection: AUTH_CONNECTION.GOOGLE,
  authConnectionId: 'w3a-google',
  groupedAuthConnectionId: 'aggregate-sapphire',
})

await disconnect()
```

Unlike `web3auth.login()`, the `connectTo` hook resolves with `null` instead of throwing when
sign-in fails. Check the result or
`error`. For the custom JWT flow's token requirements, see
[Custom authentication](/embedded-wallets/sdk/react-native/advanced/custom-authentication#bring-your-own-jwt-idtoken).

### Step 8: Blockchain calls and Wallet Services

```tsx
import { useWeb3Auth } from '@web3auth/react-native-sdk'
import { createWalletClient, custom } from 'viem'

const { connection } = useWeb3Auth()

// Inside an event handler, after sign-in
const walletClient = createWalletClient({ transport: custom(connection!.ethereumProvider!) })
const [address] = await walletClient.getAddresses()
```

To use Wagmi, see [Ethereum hooks (Wagmi)](/embedded-wallets/sdk/react-native/ethereum-hooks).

**Solana:** follow [Solana hooks](/embedded-wallets/sdk/react-native/solana-hooks).

## Verification checklist

- `@web3auth/react-native-sdk` is `^10.0.0`.
- `react-native-quick-crypto` is installed in a version that matches your app (1.x for React
  Native 0.75+ with the New Architecture, 0.7.x otherwise).
- Legacy packages are removed (`@web3auth/ethereum-provider`, `@web3auth/solana-provider`,
  `react-native-get-random-values`).
- `import '@web3auth/react-native-sdk/setup'` is the first line of the entry file, and
  `globals.js` is deleted.
- Metro uses `withWeb3Auth(getDefaultConfig(__dirname))`.
- Babel includes `@babel/plugin-transform-export-namespace-from`.
- `web3authConfig.ts` exports a `Web3AuthContextConfig` without `privateKeyProvider`,
  `loginConfig`, or `mfaLevel`.
- `redirectUrl` uses `://auth` and is allowlisted on the dashboard.
- The app is wrapped in `Web3AuthProvider`, with no `new Web3Auth` or `.init()`.
- Sign-in uses `connectTo` with `AUTH_CONNECTION`, and the code handles a `null` result.
- EVM code uses `connection.ethereumProvider`, and Solana code uses the Solana hooks.
- Solana chain IDs are `0x65`, `0x66`, or `0x67`.
- Expo: `"main": "index.ts"` and the entry file exists.
- The app builds and signs in on iOS and Android after `pod install` (bare) or `npx expo prebuild`
  (Expo).
