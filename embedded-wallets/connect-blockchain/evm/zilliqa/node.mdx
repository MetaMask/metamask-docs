While using the Embedded Wallets Node.js SDK, you get a viem WalletClient on successful authentication. This signer can be used with [viem](https://viem.sh/) to make [Zilliqa](https://ethereum.org/) blockchain calls like getting the user's account, fetching balance, signing transactions, sending transactions, reading from and writing to smart contracts, etc.
