While using the Embedded Wallets React Native SDK, you get a [`EIP1193`](https://eips.ethereum.org/EIPS/eip-1193) provider, similar to the [MetaMask Provider](/metamask-connect/evm/reference/provider-api/). Use it with libraries such as [viem](https://viem.sh) or [ethers](https://docs.ethers.org/v6/) to make [Ethereum](https://ethereum.org/) blockchain calls like getting the user's `account`, fetching `balance`, `sign transaction`, `send transaction`, `read` from and `write` to the smart contract, etc.

## Configure the chain

Enable the chain for your project on the [Embedded Wallets dashboard](https://developer.metamask.io/),
or add it to `web3AuthOptions.chains` with `chainNamespace: CHAIN_NAMESPACES.EIP155` and the chain
details above. See [Configure the SDK](/embedded-wallets/sdk/react-native#configure-the-sdk).
