Set up the SDK as described in [Get started](/embedded-wallets/sdk/react-native/), with the chain
configured on the dashboard or in `web3AuthOptions.chains`. After sign-in, read the EIP-1193
provider from `useWeb3Auth().connection` and create viem clients:

```tsx
import { useWeb3Auth } from '@web3auth/react-native-sdk'
import { createPublicClient, createWalletClient, custom } from 'viem'

const { connection } = useWeb3Auth()

// Call after the user signs in (isConnected is true)
const transport = custom(connection!.ethereumProvider!)
const walletClient = createWalletClient({ transport })
const publicClient = createPublicClient({ transport })
```
