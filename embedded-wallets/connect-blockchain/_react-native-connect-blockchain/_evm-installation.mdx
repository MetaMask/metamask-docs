Use any [EIP-1193](https://eips.ethereum.org/EIPS/eip-1193) compatible library with the provider
from the SDK. These examples use [viem](https://viem.sh):

```bash npm2yarn
npm install viem
```

To use Wagmi hooks instead, see
[Ethereum hooks (Wagmi)](/embedded-wallets/sdk/react-native/ethereum-hooks).
